1 - Click on the (<> Code) button and then Download Zip.

2 - Extract the folder to the path of your choice.

3 - Go to Windows Security / Virus & Threat Protection / under Virus & Threat Protection click Manage Settings, go to Exclusions / Add or remove exclusions / + Add an exclusion, and add the launcher folder. This ensures you can re-enable Windows Defender without any issues.

4 - Open CS2.

5 - Run fadedlauncher.exe.

At this point, you should see the Changer HUD on your screen. The HUD can be hidden with the Insert key, but you can change this in the settings.
